# Android local archive — 2026-10-08

Snapshot of local Android project variants before removing Android development files from the Mac.

- `local-projects/AndroidStudioProjects`: twelve project folders, including local-only practice projects.
- `local-projects/IdeaProjects/CapstoneDesign`: separate backend changes and newly added source files.
- `local-projects/HomeProject`: the Android/backend project previously stored at the home-directory root.
- `local-projects/HomeStaging`: Android source files recovered from the home repository index, including files missing from disk.
- `local-projects/MobileCourse`: the related backend copy from mobile programming coursework.

Generated builds, IDE caches, local SDK paths and private credential files are excluded. Literal passwords in application configuration are replaced with environment placeholders. `ARCHIVE_MANIFEST.json` records the file hashes, origins and redactions; it does not contain secret values.

This branch is an archive, not a merged runnable application. Each variant is stored separately to preserve its local source state. Existing development branches are unchanged.
